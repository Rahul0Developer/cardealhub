Marketplace Functional Requirements
The Filter and Search options must be fully operational:

Search cars by Brand, Model, Year, Fuel Type, Transmission, City, Price Range, KM Driven.

Combine multiple filters (e.g., "Hyundai + Diesel + Mumbai + ₹5–10 Lakhs").

Filters must dynamically update listings without page reloads (AJAX or smooth UI refresh).

The Buy Now Button must be fully functional:

Clicking "Buy Now" triggers the transaction flow:

Redirect user to payment initiation.

Confirm purchase after successful payment.

Update car status to "Sold" and hide from marketplace.

Handle edge cases: Car already sold, payment failed, user not logged in.

Zero Dead Links Rule:

No page, button, or link should be non-functional.

Every action must provide valid navigation, feedback, or UI response.

404 and 500 error placeholders must be replaced with real pages (e.g., No Cars Available, Payment Error).
